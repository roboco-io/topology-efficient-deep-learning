# Track A 벤치마크 최종 결과

## 실험 개요

**가설**: PH 요약 피처를 사용하면 더 작은 모델로 유사 성능을 달성하여 추론 비용을 절감할 수 있다.

**성공 기준**:
1. 효율 시나리오: 성능 하락 ≤1%p (F1) + 추론시간 ≥30% 절감
2. 성능 시나리오: 동일 추론시간에서 성능 +1~2%p 개선

## 결론

### 가설 검증 결과: **실패**

PH-MLP는 모든 데이터셋에서 InceptionTime 대비 **8~32%p 낮은 성능**을 보였다.

| 기준 | 결과 |
|------|------|
| 효율 시나리오 (≤1%p 하락) | ❌ 실패 (8~32%p 하락) |
| 성능 시나리오 (+1~2%p 개선) | ❌ 실패 |

### 데이터셋별 분석

1. **ECG200**: 가장 작은 성능 차이 (-8.4%p)
   - 짧은 시계열 (96 포인트)에서 PH가 상대적으로 효과적

2. **FordA**: 큰 성능 차이 (-28.9%p)
   - 긴 시계열 (500 포인트)에서 서브샘플링으로 인한 정보 손실

3. **ElectricDevices**: 가장 큰 성능 차이 (-32.2%p)
   - 다중 클래스 (7개)에서 PH 피처의 판별력 부족
   - Random (14.3%) 대비 개선은 있으나 제한적

4. **Wafer**: 중간 성능 차이 (-13.0%p)
   - PH-MLP가 상대적으로 양호 (0.833)
   - 불균형 데이터에서 위상 피처가 일부 효과

5. **UWaveGestureLibraryAll**: 타임아웃
   - 945 포인트 시계열에서 PH 계산이 비효율적

### 원인 분석

1. **정보 손실**: Takens embedding + PH vectorization 과정에서 시계열의 미세한 패턴 손실
2. **계산 비용**: 긴 시계열에서 PH 계산이 비효율적 (O(n³))
3. **다중 클래스 한계**: PH 피처가 복잡한 분류 경계를 표현하기 어려움

### 후속 방향

1. **Track A 조건부 결론**: "짧은 시계열 (≤100 포인트) + 이진 분류"에서만 PH 접근이 유망
2. **Track B/C 검토**: 그래프 데이터나 모델 압축에서 위상/구조 수학 적용 재검토
3. **하이브리드 접근**: PH 피처를 보조 입력으로 사용하는 앙상블 모델 검토
