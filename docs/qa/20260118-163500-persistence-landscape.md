# Q: Persistence Landscape가 뭐야?

## A: "데이터의 산맥 그리기"

### 쉬운 비유: 스카이라인 그리기

도시의 건물들을 멀리서 보면 **스카이라인** 이 보이죠?

```text
건물들                           스카이라인
                                     /\
  ■                                 /  \    /\
  ■  ■                             /    \  /  \
  ■  ■  ■                         /      \/    \
 ─────────        →              ─────────────────
```

Persistence Landscape도 비슷해요!

데이터에서 발견한 **"구멍"이나 "연결"** 같은 특징들을 **산처럼** 그립니다.
- **높은 산** = 중요한 특징 (오래 유지됨)
- **낮은 산** = 덜 중요한 특징 (금방 사라짐)

### 왜 이런 게 필요할까?

컴퓨터는 "구멍이 있다/없다" 같은 말을 이해 못해요.
대신 **숫자 목록(벡터)**을 좋아합니다!

```text
[구멍 있음, 고리 2개, ...]     →     [0.5, 0.8, 0.3, 0.1, ...]
     (사람 언어)                        (컴퓨터 언어)
```

Persistence Landscape는 위상적 특징을 **숫자 목록으로 바꿔주는** 방법입니다.

### 작동 원리: 텐트 치기

각 특징(구멍, 연결 등)마다 **텐트** 를 하나씩 칩니다.

```text
특징 A (오래 살아남음)           특징 B (금방 사라짐)

      /\                              /\
     /  \                            /  \
    /    \                          ────────
   /      \
  /        \
 ────────────
  [높은 텐트]                      [낮은 텐트]
```

**규칙**:
- 특징이 **오래 유지될수록** → 텐트가 **높아짐**
- 특징이 **금방 사라지면** → 텐트가 **낮아짐**

### 여러 텐트 합치기

텐트가 여러 개면 겹쳐서 그립니다:

```text
텐트 3개를 합치면...

    /\
   /  \      /\          가장 높은 선 = λ₁ (1등)
  / /\ \    /  \         두번째 높은 선 = λ₂ (2등)
 / /  \ \  /    \
──────────────────→ 시간
```

- **λ₁ (람다 1)**: 각 시점에서 가장 높은 텐트 따라가기
- **λ₂ (람다 2)**: 각 시점에서 두 번째로 높은 텐트 따라가기
- ...계속

### 실제 예시: 심전도 분류

```text
[심전도 파형] → [구멍/연결 찾기] → [텐트 그리기] → [숫자 목록] → [정상/비정상 판별]
   ~~~∧~~~        ●   ●           /\  /\         [0.5, 0.3,      "정상입니다"
                  ● ● ●          /  \/  \          0.1, ...]
```

### 왜 Landscape가 좋을까?

| 장점 | 설명 |
| ---- | ---- |
| 안정적 | 데이터가 조금 바뀌어도 산 모양은 비슷 |
| 계산 가능 | 여러 데이터의 평균 산맥을 구할 수 있음 |
| 정보 보존 | 원래 특징을 거의 다 기억함 |
| 빠름 | 다른 방법보다 계산이 빠름 |

### 다른 방법과 비교

위상적 특징을 숫자로 바꾸는 방법은 여러 가지예요:

| 방법 | 비유 | 장점 | 단점 |
| ---- | ---- | ---- | ---- |
| **Landscape** | 산맥 스카이라인 | 정보 많이 보존, 빠름 | 숫자가 좀 많음 |
| **Image** | 히트맵 (온도 지도) | 직관적 | 느림 |
| **Statistics** | 평균/최대값만 | 아주 빠름 | 정보 손실 |

### 이 프로젝트 실험 결과

ECG200 데이터셋에서 테스트한 결과:

| 방법 | 정확도 (F1) | 속도 |
| ---- | ---- | ---- |
| **Landscape** | **0.75** (1등!) | 3ms |
| Statistics | 0.69 | 2ms |
| Image | 0.61 | 39ms |

**Landscape가 가장 정확하면서도 빨랐어요!**

### 정리

> **Persistence Landscape** = 데이터의 위상적 특징들을 **산맥처럼** 그려서
> 컴퓨터가 이해할 수 있는 **숫자 목록**으로 바꾸는 방법

중요한 특징은 높은 산, 덜 중요한 특징은 낮은 산으로 표현됩니다.

## 더 알고 싶다면 (수학적 정의)

각 위상적 특징 (birth b, death d)에 대해 텐트 함수:

```text
Λ(t) = max(0, min(t - b, d - t))
```

이 함수는 b에서 시작해서 (b+d)/2에서 최고점, d에서 0이 되는 삼각형입니다.
