# Q: Vietoris-Rips filtration이란?

## A: "친구 관계 확장하기" 게임

### 쉬운 비유: 운동장의 친구들

운동장에 친구들이 흩어져 서 있다고 상상해보세요.

**규칙**: "N미터 안에 있는 사람끼리는 손을 잡는다"

```text
[1미터 규칙]              [3미터 규칙]              [10미터 규칙]

   철수    영희              철수---영희              철수---영희
                                                      |  \  /  |
   민수    지수              민수    지수              민수---지수

 (아무도 안 잡음)         (가까운 애들만)          (다 같이 손잡음!)
```

- **거리를 늘리면** → 더 많은 친구가 연결됨
- **거리를 줄이면** → 진짜 가까운 친구만 연결됨

이게 바로 **Vietoris-Rips filtration**입니다!

### 핵심 아이디어

| 거리(ε) | 무슨 일이 생기나? |
|---------|-------------------|
| 아주 작음 | 점들만 따로따로 있음 |
| 조금 늘림 | 가까운 점끼리 선으로 연결 |
| 더 늘림 | 세 점이 연결되면 삼각형 생김 |
| 많이 늘림 | 전부 하나로 뭉침 |

### 왜 "filtration"(여과)이라고 부를까?

커피 필터처럼 **점점 더 많은 것을 통과시키기** 때문입니다.

```text
거리 작음 ──────────────────────────────> 거리 큼

[점만]  →  [선 생김]  →  [삼각형]  →  [전부 연결]
  ●         ●──●         ●──●          ●──●
  ●         ●  ●         ●──●          ●──●
                          (면)         (덩어리)
```

거리를 천천히 늘려가면서 "언제 구멍이 생기고, 언제 사라지는지" 관찰합니다.

### 이걸 왜 쓰나요?

**데이터의 "모양"을 알아내기 위해서!**

예를 들어 도넛 모양으로 점들이 흩어져 있다면:

```text
    ● ● ●
  ●       ●       거리를 늘려가면...      구멍이 보인다!
  ●       ●       ──────────────>        ◯ (가운데 빈 원)
  ●       ●
    ● ● ●
```

- 구멍이 **일찍 생겨서 오래 남으면** → 진짜 구멍
- 구멍이 **금방 생겼다 사라지면** → 그냥 노이즈

### 실생활 예시

| 분야 | 사용법 |
|------|--------|
| 심장 박동 | 심전도 데이터에서 비정상 패턴 찾기 |
| 단백질 | 분자 구조의 구멍과 고리 분석 |
| 뇌 연구 | 뇌 신경망의 연결 패턴 발견 |
| 이미지 | 물체의 형태 인식 |

### 이 프로젝트에서의 사용

Track A 실험에서 시계열(심전도 같은 파형)을 분석할 때:

```text
[심전도 파형]  →  [점들로 변환]  →  [VR Filtration]  →  [특징 추출]
   ~~~∧~~~         ● ● ●           연결 패턴 분석       "이건 정상이다"
                   ●   ●
```

파형을 점 집합으로 바꾼 뒤, 거리를 늘려가며 어떤 구조가 나타나는지 봅니다.

### 정리

> **Vietoris-Rips filtration** = 점들 사이의 거리 기준을 점점 늘려가면서,
> 연결 → 삼각형 → 덩어리가 되는 과정을 관찰하는 방법

이를 통해 데이터에 숨겨진 **구멍, 고리, 덩어리** 같은 "모양의 특징"을 찾아냅니다.

## 더 알고 싶다면 (수학적 정의)

점 집합 X와 거리 ε에 대해:

```text
VR(X, ε) = { 모든 점 쌍의 거리가 ε 이하인 점들의 집합 }
```

ε를 0부터 ∞까지 늘려가면 복합체가 점점 커지는 "filtration"이 만들어집니다.
